## Overview

Social0 is built around one idea: write once, send everywhere. You prepare content in the dashboard (or via CLI, API, or MCP), choose accounts, then publish now or schedule for later.

## The flow

1. **Connect accounts** — From **Dashboard** → **Connections**, link the platforms you use (Twitter/X, LinkedIn, Instagram, and more).
2. **Create** — Open the **Composer**, write your text, and add photos or video if you want.
3. **Choose where it goes** — Pick which connected accounts receive the post. You can tailor copy or settings per platform when needed.
4. **Publish or schedule** — Hit **Post now**, or set a date and time. Scheduled posts go out automatically.
5. **Track** — Drafts, scheduled, and published posts live in **Posts**. The calendar and queue help you see what’s coming up.

## Where you work

| Place | What it’s for |
| ----- | ------------- |
| **Composer** | Write and send a single post |
| **Posts** | Browse drafts, scheduled, and published |
| **Calendar / Queue** | Plan timing across days |
| **Connections** | Add or remove social accounts |
| **Billing** | Plan limits and upgrades |

## Beyond the dashboard

Same publishing pipeline, different door:

- [CLI](/docs/cli) — terminal, CI, and agents with a shell
- [REST API](/docs/api) — your own backends and automations
- [MCP](/docs/mcp) — AI assistants when you can’t use the CLI

## Tips

- Connect accounts before you draft — the Composer is more useful when there’s somewhere to send.
- Free includes limited accounts and lifetime posts; drafts don’t count toward the post quota.
- Timezone in **Settings** controls how scheduled times are interpreted.

## Common questions

**Q: Do I need a different post for each platform?**  
A: Not by default. One draft can go to many accounts. You can adjust text or platform options when a network needs something different.

**Q: What happens if a publish fails on one account?**  
A: Other accounts can still succeed. Check **Posts** for status per account, and see [Troubleshooting](/docs/troubleshooting) if something keeps failing.
