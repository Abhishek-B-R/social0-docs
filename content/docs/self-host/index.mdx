## Overview

**[social0.app](https://social0.app)** is the hosted product. Its current production codebase is **not** open source.

What you can self-host is the **open-source Social0 v1** edition — a Next.js monolith published as [social0-selfhost](https://github.com/Abhishek-B-R/social0-selfhost) (AGPL-3.0; package name `social0-v1`). It includes a dashboard, REST `/v1`, and works with the public [CLI](/docs/cli) and [MCP](/docs/mcp) packages when you point them at your instance.

| | Hosted ([social0.app](https://social0.app)) | Self-host ([social0-selfhost](https://github.com/Abhishek-B-R/social0-selfhost)) |
|--|---------------------------------------------|----------------------------------------------------------------------------------|
| Source | Closed / proprietary | Open (AGPL-3.0; package `social0-v1`) |
| Stack | Current SaaS app (private) | Next.js monolith (OpenNext → Workers or Node) |
| Billing | SaaS plans | Turn off with `BILLING_ENABLED=false` for unlimited self-host limits |
| Growth automation | Auto-repost / auto-plug on hosted | **Not implemented** in v1 cron (jobs no-op) |
| Updates | Automatic | You pull and redeploy |

Core compose, schedule, publish, connections, and REST `/v1` work on self-host. It is **not** a 1:1 clone of every hosted feature — don’t expect full parity with social0.app.

Clone only `https://github.com/Abhishek-B-R/social0-selfhost.git` (a `social0-v1` GitHub path is not the public repo).

## Cost (typical)

You can keep data services on free tiers. The usual paid line item is Cloudflare Workers:

| Piece | Typical cost |
|-------|----------------|
| **Cloudflare Workers Paid** | ~**$5/month** — preferred path for the full app Worker (~4 MiB gzip) |
| **Postgres** | Free tier (e.g. Neon, Supabase) is enough to start |
| **Upstash Redis** | Free REST database is enough for small instances |
| **Cloudflare R2** | Free allowance for media; pay only if you exceed it |
| **Domain** | Whatever you already pay (or Cloudflare DNS) |

Workers **Free** is fine for the **cron-only** Worker if the app runs on Docker/Node elsewhere. The full app Worker usually needs Workers Paid unless you [trim unused platforms](https://github.com/Abhishek-B-R/social0-selfhost/blob/main/docs/prompts/workers-free-trim-platforms.md).

## Who it's for

- People comfortable with env vars, OAuth apps, and a public HTTPS URL
- Operators who already use Cloudflare (Workers, R2, DNS)
- Contributors to the open [social0-selfhost](https://github.com/Abhishek-B-R/social0-selfhost) repo

If you only want to schedule posts, use [social0.app](https://social0.app).

## Pick an install path

| Path | Best for | Entry |
|------|----------|-------|
| **Cloudflare (preferred)** | Fewest moving parts — app, cron, R2, DNS in one account | [Requirements](/docs/self-host/requirements) → `npm run self-host` |
| **Docker + Node** | Railway, Fly, Render, VPS | [Docker](/docs/self-host/docker) + cron Worker |
| **Local development** | Trying the UI or contributing | [Development](/docs/self-host/development) |

### Cloudflare (preferred)

```bash
git clone https://github.com/Abhishek-B-R/social0-selfhost.git
cd social0-selfhost
cp .env.self-host.example .env.self-host
# Edit: APP_DOMAIN, DATABASE_URL, Upstash Redis, Google and/or Resend, R2_*
npm install
npm run self-host
```

Then add your hostname under **Workers → social0 → Domains**.

The script provisions R2, Hyperdrive, queues, and deploys the app Worker plus the cron Worker.

### Docker + Node

Run the Next.js app anywhere Node/Docker runs. You still need external Postgres, Upstash Redis, R2, and the small cron Worker (Cloudflare Free works for cron-only).

```bash
OUTPUT_STANDALONE=1 docker build -t social0 .
docker run --env-file .env.local -p 3000:3000 social0
```

See [Docker](/docs/self-host/docker) and [Reverse proxy](/docs/self-host/reverse-proxy).

### Local development

```bash
cp .env.example .env.local
docker compose up -d
npm install && npm run db:migrate && npm run dev
```

See [Development](/docs/self-host/development) and [Docker Compose](/docs/self-host/docker-compose).

## Stack at a glance

| Component | Technology |
|-----------|------------|
| App | Next.js monolith (OpenNext → Cloudflare Workers, or Node standalone) |
| Database | Postgres (free-tier hosts work) |
| Sessions / rate limits | Upstash Redis REST (free tier works) |
| Media | Cloudflare R2 |
| Schedules | Cloudflare Worker cron (~every 5 minutes) + queue |

## After deploy

1. Review [Requirements](/docs/self-host/requirements) and [Configuration](/docs/self-host/configuration)
2. Sign in, connect platforms, create an API key on **your** instance
3. Point [CLI and MCP](/docs/self-host/mcp-cli) at `https://your-domain.com/v1`
4. Schedule a test post — cron publishes within a few minutes
