## Overview

The public [CLI](/docs/cli) and [MCP](/docs/mcp) packages are thin clients over REST `/v1`. On self-host they talk to **your** Social0 v1 instance — not to social0.app — when you set the base URL to **`https://your-domain.com/v1`** and use an API key from **your** dashboard.

Create keys at **Dashboard → API keys** on your instance (`sk_live_…`). Hosted keys from social0.app will not work against a self-hosted API.

## Environment variables

| Variable | Hosted default | Self-host |
|----------|----------------|-----------|
| `SOCIAL0_API_URL` | `https://api.social0.app/v1` | `https://your-domain.com/v1` |
| `SOCIAL0_API_KEY` | From social0.app dashboard | From your instance dashboard |

Local dev:

```bash
export SOCIAL0_API_URL=http://localhost:3000/v1
export SOCIAL0_API_KEY=sk_live_…
```

## CLI

Install globally or use npx:

```bash
npm install -g social0
# or: npx social0 …

export SOCIAL0_API_URL=https://your-domain.com/v1
export SOCIAL0_API_KEY=sk_live_…

social0 login          # paste key, or rely on env
social0 whoami
social0 accounts
social0 publish --content "Hello from self-host" --platform twitter
```

Persist env in `~/.zshrc`, `~/.bashrc`, or CI secrets.

One-shot:

```bash
SOCIAL0_API_URL=https://your-domain.com/v1 SOCIAL0_API_KEY=sk_live_… social0 accounts
```

See [CLI quickstart](/docs/cli/quickstart) and [commands](/docs/cli/commands).

## MCP (local npx)

Remote MCP at `https://mcp.social0.app/mcp` targets **hosted** Social0 OAuth. For self-host, use **local stdio** with your API URL and key.

### Cursor / VS Code / Claude Desktop

```json
{
  "mcpServers": {
    "social0": {
      "command": "npx",
      "args": ["-y", "@social0/mcp"],
      "env": {
        "SOCIAL0_API_KEY": "sk_live_…",
        "SOCIAL0_API_URL": "https://your-domain.com/v1"
      }
    }
  }
}
```

Cursor: project `.cursor/mcp.json` or **Settings → MCP**. Reload MCP after changes.

Local dev JSON:

```json
"SOCIAL0_API_URL": "http://localhost:3000/v1"
```

Requires [Node.js 20+](https://nodejs.org/).

### Verify

Ask the agent: “List my Social0 accounts.” It should call your instance, not social0.app.

```bash
curl -sH "Authorization: Bearer $SOCIAL0_API_KEY" "$SOCIAL0_API_URL/accounts"
```

## REST API docs

Path shapes are documented under [API](/docs/api). Hosted OpenAPI at [api.social0.app/docs](https://api.social0.app/docs) is for the **cloud** product — use it as a guide, but confirm against **your** v1 instance (`/v1/accounts`, `/v1/posts`, …). Self-host and hosted may diverge over time.

```bash
curl -sH "Authorization: Bearer $SOCIAL0_API_KEY" "$SOCIAL0_API_URL/accounts"
```

## Prerequisites

1. Self-hosted instance reachable at your public URL (or localhost for dev)
2. At least one [connected platform](/docs/dashboard/connections) on that instance
3. API key created on **that** instance — keys from social0.app do not work on self-host
